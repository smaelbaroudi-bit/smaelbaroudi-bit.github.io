# Prescripteur d'exercices — version installable

Version compilée (PWA) de l'application : https://smaelbaroudi-bit.github.io/prescripteur/

Ouvrir l'adresse dans Chrome (Android) ou Safari (iPhone), puis « Installer l'application » / « Sur l'écran d'accueil ».
L'application fonctionne hors ligne après la première ouverture et ne contient aucune donnée patient.
